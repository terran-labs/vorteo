### Maintenance

- Factory can start and recover a confined Host Builder using the selected installation account. A revoked account or an unsafe provider configuration prevents the session from opening. Host delivery uses the project's private checkout and records release evidence in daemon state.

## Maintenance review

Managed startup and recovery were tested with a disposable account and a simulated provider. Native delivery was exercised with disposable Git repositories. The first unattended issue with real managed accounts remains an installation acceptance check.
