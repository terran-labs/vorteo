### Fixes

- Dictation failures say what actually happened: the Host's speech service did not respond, the transcription took too long, dictation is not set up, or the Host is restarting or installing an update. A slow speech service no longer reads as a lost connection.
- Long recordings no longer fail on a fixed timer while the Host's speech service is still working through them, and the dictation overlay says the Host is still transcribing.
- Anywhere in the app, a request the Host did not answer in time says so and suggests checking the connection, instead of claiming the connection was lost.
