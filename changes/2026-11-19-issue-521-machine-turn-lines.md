### Features

- Machine turns in a thread collapse to one muted line: agent messages, finished and closed agent notifications, system rows and background task notifications show the sender, kind, time and first words, adjacent ones share a line with a count, and pressing the line shows the rows as before. Your own messages, question answers included, keep full weight, as do errors, permission requests, failed or running calls and the first row of a thread. The Full chat display shows every row as before. Display only; what the model receives is unchanged.
